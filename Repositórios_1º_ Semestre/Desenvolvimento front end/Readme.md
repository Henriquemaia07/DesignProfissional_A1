# 🎨 Desenvolvimento Front-end

Este repositório documenta minha jornada no **Desenvolvimento Front-end** durante o **1º Semestre** do curso de Análise e Desenvolvimento de Sistemas na UDF.

Esta é a minha área de foco para transformar wireframes e designs em interfaces de usuário (UI) funcionais e agradáveis, garantindo uma ótima Experiência do Usuário (UX).

---

## 💡 Objetivo da Disciplina

O principal objetivo desta disciplina é criar a base para a construção de qualquer interface web moderna, aprendendo a estrutura, o estilo e a interatividade da web:

| Foco | Descrição |
| :--- | :--- |
| **Estrutura (HTML)** | Organizar o conteúdo de forma semântica e acessível. |
| **Estilo (CSS)** | Aplicar design, responsividade e layout visualmente atraentes. |
| **Interatividade (JavaScript)** | Adicionar comportamento e manipular elementos da página em tempo real. |

## 🛠️ Tecnologias e Conceitos Explorados

Aqui estão as principais tecnologias e conceitos abordados nos projetos desta pasta:

### Linguagens Fundamentais
* **HTML5:** Estrutura e marcação semântica.
* **CSS3:** Estilização, Seletores, Flexbox e Grid Layout.

### Conceitos Essenciais
* **Responsividade:** Criação de layouts que se adaptam a diferentes tamanhos de tela (desktop, tablet e mobile) utilizando **Media Queries**.
* **Experiência do Usuário (UX):** Entender a navegação e a hierarquia visual para guiar o usuário.
* **Versionamento:** Todos os projetos são controlados com Git e hospedados no GitHub.

## 📁 Estrutura dos Projetos

Os projetos estão organizados em subpastas, cada uma representando um exercício, desafio ou trabalho prático:

| Subpasta (Exemplo) | Foco Principal |
| :--- | :--- |
| `Exemplo_Layout_Responsivo` | Aplicação de Media Queries e conceitos de Mobile First. |
| `Exemplo_Formularios_Acessiveis` | Práticas de acessibilidade em HTML e validação de formulários. |
| `Projeto_Final_LandingPage` | Projeto completo integrando HTML, CSS e responsividade. |
