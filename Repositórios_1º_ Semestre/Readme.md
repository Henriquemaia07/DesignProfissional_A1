# 📚 Repositórios do 1º Semestre

Bem-vindo à coleção de trabalhos e projetos desenvolvidos durante o **1º Semestre** do curso de **Análise e Desenvolvimento de Sistemas** na UDF.

Este repositório principal serve como um **índice** para as minhas principais áreas de estudo e crescimento profissional.

---

## 🧭 Visão Geral do Semestre

O primeiro semestre focou na construção da fundação técnica, lógica e de design, essenciais para qualquer profissional de tecnologia. As disciplinas abordadas estabeleceram a base para o desenvolvimento Full Stack.

## 🔗 Módulos e Disciplinas

## 🏆 Habilidades Consolidadas

Ao concluir estas disciplinas, consolidei a capacidade de:

* **Pensar Logicamente:** Estruturar soluções antes de codificar.
* **Criar e Estilizar:** Desenvolver interfaces web funcionais e visualmente agradáveis.
* **Organizar Dados:** Projetar a espinha dorsal de um sistema (Banco de Dados).
* **Foco no Usuário:** Aplicar o design para otimizar a experiência.
