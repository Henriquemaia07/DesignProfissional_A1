# 🗂️ Modelagem de Banco de Dados - UDF

Bem-vindo ao repositório de projetos da disciplina de **Modelagem de Banco de Dados** do Centro Universitário do Distrito Federal (**UDF**).

Este espaço é dedicado ao armazenamento e versionamento de modelos, diagramas e scripts desenvolvidos durante a disciplina, demonstrando a aplicação prática dos conceitos de banco de dados relacionais.

---

## 📂 Projeto Principal: Cidade Inteligente - Agronegócio

O foco deste projeto é desenvolver uma solução de banco de dados completa para um sistema de **Cidade Inteligente** no setor do **Agronegócio**.

## 🛠️ Tecnologias e Ferramentas Utilizadas

Este projeto foi desenvolvido utilizando as seguintes ferramentas:

* **Modelagem (Conceitual e Lógica):** **brModelo**
* **SGBD (Sistema Gerenciador de Banco de Dados):** **MySQL**
* **Linguagem:** SQL (Structured Query Language)

---

## 🚀 Competências Demonstradas

* Análise de requisitos para modelagem de dados.
* Desenvolvimento de Modelos Entidade-Relacionamento (DER).
* Transformação do modelo conceitual para o modelo lógico.
* Implementação do esquema de banco de dados via DDL no MySQL.
