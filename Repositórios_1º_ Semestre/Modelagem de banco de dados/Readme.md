# 🗄️ Modelagem de Banco de Dados

Este repositório contém os materiais desenvolvidos na disciplina de **Modelagem de Banco de Dados**, cursada no **1º Semestre** de Análise e Desenvolvimento de Sistemas na UDF.

O foco desta área é projetar e organizar a estrutura de dados de sistemas de forma eficiente, garantindo a integridade, a segurança e a performance das informações.

---

## 💡 Objetivo da Disciplina

O principal objetivo do módulo é capacitar na criação de modelos robustos, abrangendo desde a concepção teórica até a implementação prática:

1.  **Conceitos Fundamentais:** Entender a diferença entre dados, informação e sistemas de gerenciamento de banco de dados (SGBDs).
2.  **Modelagem Conceitual:** Desenvolver o Modelo de Entidade-Relacionamento (MER).
3.  **Modelagem Lógica:** Transformar o MER em um modelo relacional.
4.  **Normalização:** Aplicar as formas normais para eliminar redundâncias e inconsistências (1FN, 2FN, 3FN).

## 🛠️ Conteúdo e Técnicas Exploradas

| Conceito-Chave | Detalhes e Aplicação |
| :--- | :--- |
| **Entidade-Relacionamento (E-R)** | Diagramas para mapear entidades, atributos e os relacionamentos entre elas (1:1, 1:N, N:M). |
| **Chaves** | Definição de Chaves Primárias (`PK`), Chaves Estrangeiras (`FK`) e chaves candidatas. |
| **Álgebra e Cálculo Relacional** | Base teórica para a manipulação e recuperação de dados. |
| **Linguagem SQL** | Prática na definição de dados (`DDL`) e manipulação de dados (`DML`). |

### Ferramentas e Linguagens (Exemplos)
* **MySQL / PostgreSQL:** SGBDs utilizados para implementação e testes.
* **Ferramenta de Modelagem:** Uso de ferramentas visuais (como o **MySQL Workbench** ou similares) para desenhar os diagramas.
* **SQL:** Linguagem padrão para consultas e gerenciamento.

## 📁 Estrutura da Pasta

Esta pasta está organizada para mostrar o processo completo de modelagem de um projeto:

* `Estudos_de_Caso/`: Análises e resoluções de problemas de modelagem.
* `Modelos_Conceituais/`: Diagramas MER e documentação do projeto.
* `Scripts_SQL/`: Códigos (`CREATE TABLE`, `INSERT`, `SELECT`) para a criação e povoamento do banco de dados.

---

### 🔑 Por que é importante?
A modelagem correta é a espinha dorsal de qualquer aplicação. Um modelo bem-feito garante que o sistema seja escalável, rápido e tenha dados confiáveis.
