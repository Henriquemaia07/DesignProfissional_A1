# 💻 Algoritmos e Pensamento Computacional

Este repositório faz parte da jornada do **1º Semestre** do curso de **Análise e Desenvolvimento de Sistemas** na UDF, focado em construir a base essencial de **lógica e estrutura** para a programação.

O objetivo desta disciplina é transformar problemas complexos em sequências claras e executáveis de instruções, uma habilidade fundamental para qualquer desenvolvedor.

---

## 🎯 Objetivo da Disciplina

Dominar o **Pensamento Computacional** para:

1.  **Decomposição:** Quebrar um problema grande em partes menores e gerenciáveis.
2.  **Reconhecimento de Padrões:** Identificar similaridades entre problemas para aplicar soluções existentes.
3.  **Abstração:** Focar na informação essencial, ignorando detalhes irrelevantes.
4.  **Algoritmos:** Desenvolver a solução passo a passo de forma lógica e sequencial.

## 📁 Conteúdo e Estrutura

Esta pasta armazena o material prático e conceitual desenvolvido para exercitar a lógica de programação:

| Tópico Principal | Conteúdo Desenvolvido |
| :--- | :--- |
| **Conceitos Fundamentais** | Variáveis, tipos de dados e operadores. |
| **Estruturas de Decisão** | Implementação de lógica condicional (`if`, `else if`, `else`) para controle de fluxo. |
| **Estruturas de Repetição** | Utilização de laços (`for`, `while`) para automação de tarefas repetitivas. |
| **Funções e Modularização** | Organização de código em blocos reutilizáveis. |

## 🛠️ Ferramentas Utilizadas

O foco principal aqui é a lógica, que é **independente da linguagem**. No entanto, a implementação dos exercícios foi realizada utilizando:

| Ferramenta | Propósito |
| :--- | :--- |
| **Linguagem C** | Utilizada para a implementação de baixo nível e para reforçar os conceitos de memória e eficiência. |
| **Pseudocódigo / Portugol** | Uso de uma linguagem simplificada para o primeiro rascunho lógico dos algoritmos. |
